Privacy Policy - EmotionalDesignsCo Etsy Auto-Pin

Effective date: October 31, 2026

This policy describes how the "EmotionalDesignsCo Etsy Auto-Pin" application ("the App") uses the Pinterest API.

1. Who operates this App

The App is operated by EmotionalDesignsCo, a single-owner Etsy shop (etsy.com/shop/EmotionalDesignsCo). It connects to one Pinterest business account, also owned and operated by EmotionalDesignsCo. The App is not distributed to or used by any other person, business, or Pinterest account.

2. What the App does

The App creates Pins on the EmotionalDesignsCo Pinterest account whenever a new product listing is published on the EmotionalDesignsCo Etsy shop. Each Pin links back to the corresponding, already-public Etsy listing page.

3. Data accessed through the Pinterest API

The App uses the Pinterest API solely to create Pins (write access). It does not read, store, or process existing Pins, boards, follower data, or any other Pinterest user data. No Pinterest API data is collected, retained, shared, or sold.

4. Data used to create Pins

Content used for each Pin (title, description, image, listing URL) comes exclusively from the operator's own, already-public Etsy listings. No data about other Etsy sellers, buyers, or Pinterest users is accessed.

5. Credential handling

API credentials are stored securely and never shared with third parties or used outside the scope above.

6. Contact

Questions can be sent via Etsy shop messages at etsy.com/shop/EmotionalDesignsCo.
